Questions and answers

How to read a tree, and what Repo Tree asks GitHub for.

The tree

What is Repo Tree?

It grows a low-poly tree from any public GitHub repository, so you can see its shape at a glance: where the code lives, how big each part is, and how it got there. Type owner/repo or paste a GitHub link, or start from one of the samples.

How do I read the tree?
  • Branches are folders. A branch forks where a folder splits.
  • Thicker branches hold more files. A bigger repository grows a taller tree.
  • Leaves are files, colored by language unless you choose another way under Color leaves by: by top-level folder, how recently or how often files changed, or who owns each folder.
  • Rocks on the island are the files at the top of the repository.

Point at a branch to see its folder, and click it to pin it and zoom in.

What do the weather and the birds mean?

The weather is the repository's CI. Sunny means recent GitHub Actions runs passed, clouds mean some failed, rain means the latest run failed, and a storm means several failed in a row. The chip under the title says which.

Birds are open pull requests, each perched on the folder it changes most. Tap one to see which pull request it is.

How does the timeline work?

Timeline replays the repository from its first commit: folders sprout as they appear, and you can drag through the years or press play. The first time anyone opens a repository's timeline, it is worked out in their browser and then shared, so everyone after them gets it right away.

Can I share or save a tree?

Share copies a link that opens the same repository, branch, colors and pinned folder. PNG saves the view as an image. On a phone, they are Copy link and Export PNG under More actions.

GitHub

What can Repo Tree see when I sign in?

Public data only. Signing in asks GitHub for no permissions, so Repo Tree can't see your private repositories, and it never writes anything. It reads what anyone can see on github.com: folder and file names and sizes, Actions runs, open pull requests, and commit history.

It doesn't read your code. The one file whose contents it reads is CODEOWNERS, to say who owns each folder. For a private repository, paste a GitHub token under GitHub token in Settings instead; it is kept in this browser and sent only to GitHub.

Why sign in, and what are the “requests this hour”?

GitHub allows 60 requests an hour to anyone not signed in, shared by everyone on the same network, and a big repository can use that up in minutes. Signed in, you get your own 5,000 an hour. The account menu shows how many are left and when the count starts over; checking it doesn't use any.

Where does my sign-in go, and how do I sign out?

Signing in gives this browser a token that reads public data only. It stays in this browser, so new tabs stay signed in, and never goes into a share link. The page sends it only to GitHub, and to the Repo Tree history server when that works out a timeline for you, which uses it for that request and never stores it.

To sign out, choose the GitHub button at the top right, then Sign out, which signs out every tab. To remove Repo Tree from your GitHub account altogether, revoke it under Settings, Applications on GitHub.
