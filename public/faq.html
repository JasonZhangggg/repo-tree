Questions and answers

What Repo Tree asks GitHub for, and what signing in changes.

GitHub and your account

What can Repo Tree see when I sign in?

Public data only. Signing in asks GitHub for no permissions, so Repo Tree can't see your private repositories. It reads the same things anyone can see on github.com without signing in.

It reads names, sizes and history, not your code. The one file whose contents it reads is CODEOWNERS, to say who owns each folder.

What does Repo Tree use GitHub for?
  • The tree: the list of folders and file names, and their sizes.
  • The weather: recent GitHub Actions runs on the default branch.
  • The birds: open pull requests.
  • History and Color leaves by: commits, their dates and authors, and the CODEOWNERS file.

Nothing is written to GitHub: Repo Tree only reads.

Why sign in at all?

GitHub allows 60 requests an hour to anyone not signed in, shared by everyone on the same network. A big repository or a busy office can use that up in minutes, and then trees, weather and birds stop loading. Signed in, you get your own 5,000 an hour.

What are the “requests this hour”?

How much of that hourly allowance is left, as GitHub counts it. Opening a repository takes a handful of requests; a repository's history takes more. The count starts over at the time shown under the meter. Checking it doesn't use any.

Where does my sign-in go?

Signing in gives this browser tab a token. It stays in that tab: closing the tab forgets it, and it never goes into a share link. The tab sends it only to GitHub, and to the Repo Tree history server when that reads a repository's history for you. The history server uses it for that request and never stores it.

How do I sign out, or remove Repo Tree from my account?

Choose the GitHub button at the top right, then Sign out, or close the tab. To remove Repo Tree from your GitHub account altogether, revoke it under Settings, Applications on GitHub.

Can I see a private repository?

Signing in can't. For a private repository, paste a GitHub token with read access in Repo Tree's Settings, under GitHub token. That token is kept in this browser and sent only to GitHub.
